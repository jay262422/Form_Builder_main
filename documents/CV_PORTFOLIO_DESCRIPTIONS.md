**Dynamic Form Builder**  
*Full-Stack Web Application | React, Next.js, Node.js, MongoDB*

**Overview:**  
Built a production-ready dynamic form builder system that allows users to create, manage, and deploy complex forms through an intuitive visual interface. The application supports both technical and non-technical users with a drag-and-drop builder and programmatic form creation.

- **Visual Form Builder**: Drag-and-drop interface for creating forms without code

- **Conditional Logic**: Show/hide fields based on user input with complex condition builders
- **Form Wizard**: Multi-step form experience with progress tracking
- **Theme Customization**: Visual theme editor with color, typography, and spacing controls
- **Real-time Validation**: Client and server-side validation with custom rules
- **Form Management**: CRUD operations for forms with versioning and templates
- **REST API**: Complete backend API for form operations, submissions, and field options

**Technical Implementation:**
- **Frontend**: React 18, Next.js 14 (App Router), Tailwind CSS
- **Backend**: Node.js, Express.js, MongoDB with Mongoose
- **Architecture**: RESTful API design, modular component structure
- **State Management**: React Hooks (useState, useCallback, useMemo)
- **Form Handling**: Custom validation system, dynamic field dependencies
- **File Uploads**: Drag-and-drop file handling with validation
- **Error Handling**: Error boundaries and comprehensive error management

**Achievements:**
- Implemented complex conditional logic system supporting multiple operators and field dependencies
- Created extensible field type registry allowing easy addition of new field types
- Designed responsive UI with modern UX patterns
- Built scalable API architecture with proper error handling and validation

### 📖 Portfolio Project Page (Detailed)

# Dynamic Form Builder

**A comprehensive form builder system with visual drag-and-drop interface**

## 🎯 Project Overview

The Dynamic Form Builder is a full-stack web application that empowers users to create complex, interactive forms through an intuitive visual interface. Whether you're a developer or a non-technical user, the system provides powerful tools to build forms with advanced features like conditional logic, multi-step wizards, and real-time validation.

## ✨ Key Features

### Visual Form Builder
- Drag-and-drop interface for creating forms without writing code
- Real-time preview of form changes
- Intuitive field placement and organization

### Extensive Field Types
- **30+ Field Types**: Text, email, password, number, textarea, select, multi-select, checkbox, radio, toggle
- **Advanced Fields**: File upload, signature pad, rating stars, color picker, date/time pickers
- **Special Fields**: Currency input, percentage, phone number, address, URL, calculated fields
- **Repeating Fields**: Repeater component for dynamic field groups

### Conditional Logic
- Show/hide fields based on other field values
- Support for multiple operators (equals, contains, greater than, etc.)
- Complex condition combinations (AND, OR, NOT)
- Real-time field dependency management

### Form Wizard
- Multi-step form experience
- Progress tracking and navigation
- Step validation before proceeding
- Customizable step titles and descriptions

### Theme Customization
- Visual theme editor
- Color palette customization
- Typography controls
- Spacing and layout adjustments
- Live preview of theme changes

### Form Management
- Create, edit, duplicate, and delete forms
- Form templates library
- Form versioning
- Form analytics and submission tracking

### API Integration
- RESTful API for all form operations
- Form submission handling
- Dynamic field options from API
- Webhook support for form submissions

## 🛠️ Technology Stack

### Frontend
- **React 18** - Component library
- **Next.js 14** - Framework with App Router
- **Tailwind CSS** - Utility-first CSS framework
- **React Hooks** - State management (useState, useCallback, useMemo)

### Backend
- **Node.js** - Runtime environment
- **Express.js** - Web framework
- **MongoDB** - Database with Mongoose ODM
- **JWT** - Authentication (ready for implementation)

### Development Tools
- **PostCSS** - CSS processing
- **ESLint** - Code linting
- **Git** - Version control

## 🏗️ Architecture

### Frontend Structure
```
app/
├── layout.jsx          # Root layout
├── page.jsx            # Main dashboard
components/             # Reusable components
├── VisualFormBuilder   # Drag-and-drop builder
├── FormManager         # Form management UI
├── FormWizard          # Multi-step form
└── ThemeEditor         # Theme customization
fieldTypes/             # 30+ field type components
services/               # Business logic
utils/                  # Helper functions
```

### Backend Structure
```
routes/                 # API routes
├── forms              # Form CRUD operations
├── submissions        # Form submission handling
├── field-options      # Dynamic field options
└── dynamic-mappings   # Field dependencies
controllers/           # Request handlers
models/               # Database models
```
